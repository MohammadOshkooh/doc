   ========================================



   داکر 3 تا جز مهم داره
   Orchestration
   کارش اینه که کانتیر های زیادی که دارین رو بتونین راحتتر مدیریت کنین
   Engine/daemon
   هسته اصلی برنامه هستش. وظیفه‌ی مدیریت اشیای داکر مثل ایمیج ها و نتورک ها و والیم ها را دارد
   Runtime
   سطح پایین ترین برنامه هستش. برای ایجاد کردن و متوقف کردن کانتینر هاو دانلود ایمیج ها استفاده میشه


   ========================================
برنامه هایی که میخوایم استفاده کنیم رو بهشون میگیم ایمیج.

   restart policy:

   docker run -it --restart always python bash
   اگه بسته هم بشه باز ری استارت میشه

   docker run -it --restart unless-stopped python bash
    شبیه بالا هست بجز وقتی که دستی docker stop  بزنیم

   docker run -it --restart unless-stopped python bash

   Dockerfile

   RUN:  با استفاده از این دستور، می‌توانید دستورات مختلفی را در زمان ساخت تصویر اجرا کنید


    فرق دستور expose با دستور ports:  دستور expose  اجازه میده داخل داکر هر جقدر کانتینر که خواستند بیان روی اون پورت به برنامه وصل بشن ولی از خارج داکر نمیتونن. اما ports هم از داخل هم از خارج میتونن وصل بشن
