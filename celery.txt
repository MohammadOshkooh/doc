فرض کنید کاربر یه درخواست http میزنه و میخواد فرمت یه فیلم رو تغییر بده. شاید تغییر دان فرمت یه فیلم کار زمانبری باشد و حال ما نخواهیم کاربر رو تا پایان اتمام عملیات نگه داریم به طوری که نتواند هیچ کاری بکند.

حالا ما میایم درخواست رو میفرستیم توی یه بروکر که صف ایجاد میکنه و به ترتیب درخواست هارو پردازش میکنه و نیازی نیست کاربر تا پایان پردازش درخواست منتظر بمونه.

کارکردن با مسیج بروکر ها یه خورد سخته واسه همین میایم از سلری استفاده میکنیم. درواقع میایم روی اون بروکر سلری رو قرار میدیم که ازین به بعد با سلری کار کنیم.

سلری هم راحت تره و هم امکانات بیشتری داره.

---------------------------------------------
Celery.py
    from time import sleep

    from celery import Celery

    app = Celery('djangoProject', broker='amqp://mhmd:root@localhost:5672/mhmdvhost')

    app.autodiscover_tasks(['core.tasks'])

    @app.task
    def add(x, y):
        sleep(5)
        return x + y

    from Celery import app

    add.apply_async(args=[1,2])
